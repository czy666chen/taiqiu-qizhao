# 实时房间与其他模式实机验收 Prompts

以下 prompts 可独立执行，建议按顺序运行。每部分结束时都应留下可恢复检查点。

共同约束：只操作指定环境；房主使用 Codex 内置浏览器，成员使用 Microsoft Edge 扩展会话，两个 cookie 容器隔离；严格串行操作。记录房间码、账号昵称、页面 URL、preview/production Version ID 和每个阶段的房间版本。不要显示或重置 QA 账号密码，不要覆盖用户已有未提交改动。

## 第一部分：团战收尾与测试基线

```text
继续完成 E:\hei8chouka 的 Cloudflare 实机验收准备。

当前已知账号：
- 房主：qahost / QA房主，Codex 内置浏览器
- 成员：qamember / QA成员，Microsoft Edge
- 优先复用登录会话，不创建重复账号

请完成：
1. 确认当前部署 URL、环境和 Version ID。
2. 恢复已有实时团战房间；记录房间码、版本、比分与流水。
3. 完成刷新、断线重连、结束归档和双端只读验证。
4. 在 Edge 移动视口检查归档无横向溢出。
5. 完成 PNG、PDF、JSON 导出并核对内容。
6. 检查两端 console error、WebSocket 和关键请求失败。
7. 输出后续模式可复用的账号、浏览器和环境基线，不输出密码。

发现问题时必须按 diagnosing-bugs 流程：先建立能捕获准确症状的失败测试，再定位和最小修复；运行相关测试后只部署指定环境。
```

```text

10. 房主结束并归档；确认双方只读且云端历史可查看。
11. Edge 切换到 375×812 移动视口，检查无横向溢出。
12. 完成 PNG、PDF、JSON 导出并确认文件非空、内容正确。
13. 检查两端 console error、未处理异常、WebSocket 重连循环和 4xx/5xx。

发现问题时按 diagnosing-bugs 流程处理，只重新部署指定非生产环境，除非用户明确要求发布 production。
```

## 第四部分：实时斯诺克

```text

环境与约束：
- 房主：Codex 内置浏览器，QA房主
- 成员：Edge，QA成员
- 复用登录会话，严格串行
- 保存房间码、版本、当前局号、当前击球者和台面状态

测试流程：
1. 创建标准斯诺克实时房间并绑定两个注册席位。

9. 暂停与恢复一次。
10. 分别刷新或断线重连两端，核对角色、席位、当前局、击球者、剩余红球、分数、单杆和流水。
11. 房主结束归档，双方进入只读状态。
12. Edge 移动视口检查台面、计分和流水无横向溢出。
13. 完成 PNG、PDF、JSON 导出并核对局号和最终比分。
14. 检查 console、WebSocket、重复请求和 4xx/5xx。
```
